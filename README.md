# IT — Italian Trattoria · Web Rebuild (Pitch Mockup)

> A pitch-quality mockup for the US web presence rebuild of **IT — Italian Trattoria** (4 locations: Miami Beach + NYC).
> Built by Rayan Karim Checa as a pitch to win the engagement.

**Status:** in-build. See [REVIEW.md](./REVIEW.md) for current phase.

## What this is

A working, deployed Next.js mockup designed to be put in front of Renato and Gio Iera (founders) and their US leadership team. The goal of the mockup is to win the engagement to actually rebuild [it-trattoria.com](https://it-trattoria.com).

## Quick start

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

Then open <http://localhost:3000>.
